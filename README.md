## 📌 Présentation

Composant de **grille tarifaire** à trois formules (Basic / Professional / Master) avec un
**interrupteur Annually / Monthly** qui met à jour les prix affichés. La carte centrale est
mise en avant par un dégradé et un léger agrandissement sur desktop.

## ✨ Fonctionnalités

- **Toggle** annuel / mensuel accessible à la souris **et au clavier**.
- Mise à jour réactive des prix (`199.99` ↔ `19.99`, etc.).
- Carte « Professional » en surbrillance (dégradé violet).
- Layout en colonne sur mobile, en ligne sur desktop.

## 🛠️ Stack

Vue 3 · Vite 5 · Tailwind CSS 3.
